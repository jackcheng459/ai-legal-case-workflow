## 阶段6：庭审阶段文书撰写

**目标**：覆盖庭前准备、庭审应对、庭后跟进三个时间段的全部文书工作。

**输入**：庭审记录（含法庭调查、举证质证、法庭辩论） + 前序阶段全部材料

### 6A. 庭前准备文书（开庭前完成）

| 文书 | 内容 | 来源 |
|------|------|------|
| 庭审提纲 | 争议焦点梳理、举证顺序、质证要点、辩论框架 | 阶段5材料整合 |
| 发问提纲 | 向对方当事人/证人发问的问题清单（含预期答案和追问方向） | trial-questioner |
| 质证意见 | 对对方证据的三性分析（真实性/合法性/关联性） | evidence-organizer |
| 代理词（初稿） | 完整代理意见框架，留庭审调整空间 | defense-drafter |

### 6B. 庭审应对（开庭当天）

**庭审记录要点**（庭审后24小时内完成）：

1. **法庭归纳争议焦点**（与预判对比，标注偏差）
2. **法官询问方向**（推断裁判倾向）
3. **双方举证质证情况**（已采信/有争议/未采信）
4. **对方自认/让步**（对我方有利的关键陈述）
5. **庭审新情况**（新证据、新论点、需要回应的事项）

### 6C. 庭后跟进文书（庭审后完成）

**操作步骤**：

1. 精读庭审记录，标注关键节点
2. 分析法庭归纳的争议焦点（与预判对比）
3. 评估双方证据采信情况与证明力对比
4. 从法官询问中推断裁判倾向
5. 撰写庭审分析报告
6. 撰写庭后代理意见书（针对庭审新情况补充论证）
7. 准备最后陈述（如法院要求书面最后陈述）
8. 评估是否需要补充证据（庭后补证申请）
9. 更新调解方案（基于庭审新情况调整）

**输出模板**：详见 `references/templates.md` 中的"庭审文书模板"

**关键经验**：
- 法官反复追问的问题 = 裁判文书着墨重点
- 庭审新情况必须在庭后意见中回应
- 调解方案要务实：基于双方实际强弱，最积极方案也要留余地
- 庭审记录24小时内完成，记忆最新鲜时最准确
- 庭后代理意见书不是重复庭审发言，而是补充庭审中未能充分展开的论证

## 阶段7：格式转换与交付

**目标**：将 Markdown 格式工作成果转换为客户/法院所需格式，完成归档。

**格式转换矩阵**：

| 源格式 | 目标格式 | 工具/方法 | 适用场景 |
|--------|----------|-----------|----------|
| MD | HTML | 手写HTML模板（卡片式布局，响应式） | 案件报告展示 |
| MD | Word(.docx) | 当前平台已有文档工具；经用户授权后也可在 managed venv 中使用 python-docx | 正式法律文书（起诉状/答辩状/代理词） |
| MD | PDF | md-to-pdf-cjk skill | 正式文件归档 |
| PDF | 图片 | pdfkit-py skill `to_images` (200dpi) | 扫描件OCR前处理 |
| PDF | MD | markitdown-skill | 文档内容提取 |

**交付物分级**：

| 交付对象 | 格式 | 内容 |
|----------|------|------|
| 法院 | Word(.docx) | 起诉状/答辩状/代理词/证据目录（按法院要求格式） |
| 客户（委托人） | HTML | 案件概要报告（简化版，突出策略建议和预期结果） |
| 团队内部 | MD | 全部分析报告（含完整分析过程和法源核实） |

**客户友好版摘要要求**：

- 去除法律术语，用委托人理解的语言
- 突出三个要点：案件现状、建议方案、预期结果
- 附时间线和关键节点说明
- 标注需要客户配合的事项（补充证据、确认信息等）

**归档标准**：

```
[案件名称]/
├── 01_原始材料/          ← 客户提供的原始卷宗
├── 02_分析报告/          ← 阶段1-2产出
├── 03_起诉材料/          ← 阶段3产出（原告方）
├── 04_应诉材料/          ← 阶段4-5产出
├── 05_庭审文书/          ← 阶段6产出
├── 06_最终文书/          ← 定稿版（Word/PDF）
├── 07_工作底稿/          ← 过程文件、草稿、参考材料
└── 08_归档清单.md        ← 全部文件索引
```

**关键约束**：
- 优先使用当前平台已有且可验证的文档工具，不预设特定工具一定可用
- 确需安装 Python 包时先取得用户授权，并仅安装在 managed venv 中，禁止污染系统环境
- Word 文档格式：宋体正文/黑体标题、1.5倍行距、标准页边距
- 交付前执行文件命名检查（阶段_文书类型-版本号格式）
- 归档清单在案件结案时编制，包含全部文件索引和关键结论
