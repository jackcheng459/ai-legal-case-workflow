## 阶段1：诉前案情分析

**目标**：通读全部原始材料，建立案件全貌认知，输出结构化概要报告，为后续所有阶段提供事实锚点。

**输入**：原始卷宗目录下的全部文件（MD/PDF/图片/音频转写文本/视频）

**操作步骤**：

1. **读取卷宗结构**
   - 读取 `00_卷宗目录与阅读说明.md`，了解文件夹结构和阅读建议
   - 确认材料清单与实际文件是否一致（有无缺失或多余）

2. **逐份读取全部材料**
   - MD文件：直接 Read
   - PDF 文件：先尝试直接读取文字层；为空或明显缺页时，使用当前平台已提供且已验证的 PDF 渲染或 OCR 能力，将相关页面按约 200dpi 转为图片后读取；无转换能力时记录文件并请用户提供图片版、OCR 版或文本版，不自动安装未授权工具
   - 图片文件：直接 Read（多模态读取）
   - 音频/视频文件：转文字后 Read；标注关键时间段（如"03:15 对方承认未付款"）

3. **提取关键信息**
   - 当事人信息：名称、住所地、法定代表人、联系方式
   - 合同条款：标的、价款、付款节点、交付条件、违约责任、争议解决条款
   - 付款记录：金额、时间、方式、对应合同节点
   - 沟通记录：催款、协商、承诺、拒绝等关键对话
   - 时间节点：签约、交付、催告、违约、解除、起诉等

4. **构建结构化时间线**
   - 按时间顺序排列所有关键事件
   - 每个节点标注证据来源（文件名/页码/段落）
   - 分类标注：合同事件（签约/变更/解除）| 履行事件（交付/验收/付款）| 违约事件（逾期/拒绝/瑕疵）| 诉讼事件（催告/起诉/反诉）
   - 区分"事实事件"与"诉讼事件"

5. **梳理主体关系**
   - 绘制当事人关系图（文字描述）
   - 识别实际控制人、关联方、利益相关方
   - 标注合同签署主体与实际履行主体是否一致

6. **诉讼时效分析**
   - 识别各请求权的诉讼时效起算点
   - 计算时效届满日，评估是否存在时效中断/中止事由
   - 时效届满风险预警（标注红色）

7. **管辖初步评估**
   - 审查合同争议解决条款（协议管辖/仲裁条款）
   - 无协议时按法定管辖（被告住所地/合同履行地/侵权行为地）
   - 评估管辖权异议风险

8. **识别争议焦点**
   - 从材料中提炼核心分歧点
   - 每个焦点标注双方主张和对应证据

9. **编制证据清单**
   - 列明所有证据：编号、名称、来源、形式、证明目的、证明力评级（强/中/弱）
   - 标注待补充证据及获取方式
   - 评估证据链完整性（有无断裂环节）

10. **诉讼成本预估**
    - 诉讼费（按标的额计算）
    - 保全费+担保费（如需保全）
    - 律师费（按当地标准或约定）
    - 时间成本（结合案件程序、法院审理情况和当前规定核验，不使用固定时长承诺）

11. **提出策略建议**
    - 方案A：直接起诉（适用条件+预期效果+风险）
    - 方案B：先发律师函（适用条件+预期效果+风险）
    - 方案C：协商和解（适用条件+预期效果+风险）
    - 推荐方案及理由

**输出模板**：详见 `references/templates.md` 中的"案件概要报告模板"

**关键经验**：
- PDF扫描件：优先转图片 Read，优于 tesseract OCR
- 不跳过任何文件：即使文件名看似不重要
- 时间线是所有后续分析的锚点，务必准确、完整、可追溯
- 诉讼时效分析必须在阶段1完成，避免立案后才发现时效已过
- 管辖评估同步进行，避免阶段3才发现管辖问题

## 阶段2：对方主体核查与财产保全

**目标**：对对方当事人进行全面背景调查，评估财产保全的必要性和可行性，为起诉/应诉策略提供数据支撑。

**输入**：对方当事人名称 + 阶段1案件概要报告

**操作步骤**：

### 企业被告核查路径

| 步骤 | 操作 | 工具 |
|------|------|------|
| 2.1 | 工商基本信息查询 | 企查查 MCP |
| 2.2 | 股权结构穿透（股东、持股比例、变更历史） | 企查查 MCP |
| 2.3 | 企业风险扫描（涉诉、失信、行政处罚、经营异常） | 企查查 MCP |
| 2.4 | 司法涉诉查询（案件列表、裁判文书、执行信息） | 元典 MCP |
| 2.5 | 信用风险评估 | 元典 MCP |
| 2.6 | 空壳化特征识别（实缴vs注册资本、参保人数、经营场所） | 综合分析 |
| 2.7 | 股权变动时间线与诉讼时间线交叉比对 | 综合分析 |
| 2.8 | 知识产权资产查询（商标、专利、著作权） | 企查查 MCP |
| 2.9 | 追加被执行人线索排查（关联公司、未实缴股东、一人公司） | 综合分析 |
| 2.10 | 保全方案设计（结合标的额、资产状况、可行性） | 综合分析 |

### 个人被告核查路径

| 步骤 | 操作 | 工具 |
|------|------|------|
| 2.1 | 身份信息核验（姓名、身份证号、户籍地） | 线下材料 |
| 2.2 | 涉诉记录查询 | 元典 MCP |
| 2.3 | 失信/限消记录查询 | 元典 MCP |
| 2.4 | 关联企业任职/持股查询 | 企查查 MCP |
| 2.5 | 不动产线索（通过社保缴纳地推断常居地） | 线下调查 |
| 2.6 | 保全方案设计（银行存款/不动产/车辆/工资收入） | 综合分析 |

### 跨境要素检查

- 对方是否为外商投资企业/港澳台企业 → 评估涉外送达和管辖问题
- 对方财产是否在境外 → 评估承认与执行外国判决的可能性
- 合同是否约定境外仲裁/管辖 → 评估条款效力

**输出模板**：详见 `references/templates.md` 中的"主体核查报告模板"

**关键经验**：
- 多维交叉验证：企查查 + 元典双重验证
- 关注诉讼期间股权/法人变更（资产隔离信号）
- 参保人数、经营场所和实缴情况都只是风险信号，应结合经营、资产、人员、交易和多来源数据综合判断，不能凭单一指标认定空壳化
- 零涉诉不等于低风险：追溯更名前信息
- 追加被执行人线索在阶段2就应排查，不要等到执行阶段才发现
- 涉及一人公司股东责任时，核验现行公司法、司法解释、举证责任和个案事实后，再提出责任承担方案
